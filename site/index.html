// FEATURES

Everything at your fingertips

A HUD for your tablet

Landing, power management, quantum, operator modes, shields, targeting, salvage, mining, doors and emotes, on a two-half HUD that pages through panels. Phones get their own layout. In English, Español, Français, Deutsch or Català.

Hold-to-talk voice

"Landing gear", "engage quantum", "shields up". Hold the mic button and speak. Windows' built-in speech recognition, offline.

12 manufacturer themes

RSI, Drake, Aegis, Anvil, Origin, MISC, Crusader, Banu, Aopoa, Argo, Consolidated Outland and Esperia, with press animations, a night mode, large text and high contrast.

Layout editor

Drag buttons around and change their keys, labels, icons and animations. Share layouts as files, or pick a starter layout for Combat, Mining & Salvage, Hauling & Exploration (with a cargo notepad), the Prospector or the Vulture.

Follows your keybinds

Reads your Star Citizen keybinds, so rebinding in-game moves the button with it. An optional profile covers actions with no default key.

A proper Windows app

One installer. A window with the QR code, a tray icon, settings, start with Windows, and updates with one click.

// ANY TABLET, ANY PHONE

iPad, Android or iPhone

It runs in the browser, so there's nothing to install on the tablet. Scan the QR code, add it to your home screen, and it opens full screen like an app. The screen stays awake mid-flight.

// MAKE IT YOURS

Twelve looks, one deck

// LAYOUT EDITOR

Build your own deck

The editor shows the deck exactly as your tablet does. Drag to move and resize, pick keys from a list so they're always valid, and set colours, icons, press animations and voice phrases. Save, and your tablets switch to it by themselves.

// ON YOUR PC

One window, all the status

The app on your PC shows the QR code and pairing code to connect, and live telemetry: tablets connected, where keys go and the presses of the last minute. Voice status, settings and a log are a glance away, and it tucks into the tray while you fly.

// GET STARTED

Flying in three steps

  1. Install

    Download the installer and run it on your gaming PC. It adds Tablet Deck to the Start menu and, if you like, the Star Citizen keybind profile.

  2. Pair

    Open Tablet Deck and scan its QR code with your tablet's camera, or type the address and pairing code.

  3. Fly

    Click into Star Citizen and tap away. Keys only go through while the game is the window in front.

// FAQ

Questions

Is it free?

Yes, completely, and the source is on GitHub under the MIT license. It's a fan project, and there's no paid version.

Is it a macro tool? Is it allowed?

It presses ordinary keyboard keys, one press per tap, like a second keyboard. No automation or macros, and it doesn't touch the game's files or memory. Keys only go through while Star Citizen is the window in front.

Windows says "Windows protected your PC". Is it safe?

The installer isn't code-signed yet, so Windows doesn't know the publisher. Click More info, then Run anyway. Every release lists the installer's checksum, and all the code is public on GitHub.

What do I need?

Windows 10 or 11 on the gaming PC, and a tablet or phone with a browser on the same Wi-Fi or network. The voice commands need the English speech recognizer that comes with Windows.

Does it work on a Mac or Linux PC?

Not yet: the part that presses keys is Windows-only. The tablet can be anything with a browser.

Does it collect any data?

No accounts, ads or tracking. The app only checks GitHub for updates (you can turn that off), and the tablet loads the theme fonts from Google Fonts.
